# Kaye Commit Sense Documentation

<!-- fixme improve commit sense doc -->

| Sigil | Remark |
|-------|--------|
| `^` | file is newly Added |
| `!` | file is Deleted |
| `:` | file moved to a different Directory, content unchanged or nearly unchanged |
| `=` | directory unchanged but Filename changed, content unchanged or nearly unchanged |
| `?` | file is non-text: binary, compressed Archive, database, or encrypted blob |
| `@` | only edits are to Triage Tags and lines directly tied to them |
| `#` | edits are mostly to Documentation or code comments |
| `~` | edits are mostly reordering content or Refactoring code, behavior unchanged |
| `.` | only edits are whitespace, indentation, or blank Lines |
| `+` | ordinary edit, more lines Added than deleted (short form) |
| `-` | ordinary edit, more lines Deleted than added (short form) |
| `*` | ordinary edit, added and deleted lines roughly Balanced (short form) |
| `/` | ordinary edit, more lines Added than deleted (long form) |
| `\` | ordinary edit, more lines Deleted than added (long form) |
| `\|` | ordinary edit, added and deleted lines roughly Balanced (long form) |
